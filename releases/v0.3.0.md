# Arondo v0.3.0

**Release Date:** 2026-10-14
**Commits:** 5
**Tag:** v0.3.0

This release adds Jev System One support for Auto Model routing and a new `arondo-cli decide` subcommand, introduces LLM-based AI agent quota fetching on the Runner, and improves script output rendering and single-use session handling.

---

## Highlights

- **`arondo-cli decide` Subcommand**: New command for ultra-fast categorical decisions and classifications powered by TypeSafe AI Jev System One. Supports native JSON questions for choice, score, and noul primitives, automatic model defaulting, runner-free server execution, and ephemeral tempDir/once session cleanup.
- **Jev System One for Auto Model Routing**: Auto Model routing can now use Jev System One, configurable via `ARONDO_INNER_AUTOMODEL_METHOD`.
- **LLM-Based Agent Quota Fetching**: The Runner can run an interactive LLM loop to extract AI agent quota information, which is robust against UI changes. The method is controlled via `ARONDO_INNER_RUNNER_QUOTA_METHOD` and passed through `info.fetch`. Agent-specific Zod schemas are provided for agy, claude, and codex.

# Arondo v0.3.5

**Release Date:** 2026-10-27
**Commits:** 4
**Tag:** v0.3.5

This patch release introduces hidden automation sessions, session tags in the sidebar, agent failure diagnostics, safe handling for hyphen-prefixed prompts, persistence for native Jev decision answers, and protection against overwriting existing sessions while preserving immutable session fields.

---

## Highlights

- **Automation Sessions & Sidebar Tags**: Support for hidden, project-free automation sessions via the `--automation` CLI flag and session API without requiring a repository path. Added an automation session visibility toggle in Admin Settings and tags display in the sidebar.
- **Failure Diagnostics**: Agent failure events now provide diagnostic error reasons across WebSocket events, CLI failure handling, and session APIs for transparent root-cause tracking.
- **Safe Handling for Hyphen-Prefixed Prompts**: Prompts beginning with dashes or hyphens (such as `--help` or `- item`) are now prefixed with `--` argument delimiters for Claude, Codex, and OpenCode CLIs to prevent misinterpretation as command-line options.
- **Native Jev Decision Answer Persistence**: Fast categorical decisions run through `cli/arondo-cli decide` now persist the chosen answer map, confidence, and probability metrics on decision sessions and include them in structured JSON output.
- **Session Overwrite Prevention & Immutable Field Protection**: The session creation API rejects duplicate session IDs with a `409 Conflict`, and session updates strictly protect immutable properties (`id`, `createdAt`, `repoPath`, `projectId`, `runnerId`, `tempDir`, `automation`, `noProject`).

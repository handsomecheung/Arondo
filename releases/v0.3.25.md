# Arondo v0.3.25

**Release Date:** 2026-11-26
**Commits:** 5
**Tag:** v0.3.25

This patch release adds media file preview and HTTP Range streaming in the File Browser, paragraph-level text-to-speech with inline playback controls, session status transition to `needs_attention` on script input waits, and updated Antigravity models with automatic configuration migration.

---

## Highlights

- **Media File Preview & Range Streaming**: The Remote File Browser now previews images, audio, and video directly within the interface. File reading supports HTTP 206 Partial Content Range requests and chunked streaming for smooth playback.
- **Paragraph-Level Text-to-Speech**: In addition to full result card narration, speech playback can now be triggered for individual paragraphs via inline speaker buttons, with automated text preprocessing that cleans markdown markers, code blocks, and URLs.
- **Script Input Wait Detection (`needs_attention`)**: Sessions now automatically transition to `needs_attention` when an active script enters a blocking input wait state, including descendant processes outside the shell's process group on Linux.
- **Antigravity Model Updates & Migration**: Antigravity model configurations have been refreshed and the legacy argon group has been consolidated into the primary model list, supported by an automatic startup migration.

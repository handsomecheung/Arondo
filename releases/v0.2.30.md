# Arondo v0.2.30

**Release Date:** 2026-08-28
**Commits:** 6
**Tag:** v0.2.30

This release introduces real-time terminal output streaming over WebSocket for the Go CLI,
moves notification permissions and test controls to Settings, adds rounded PWA and Apple Touch
icons, enables reuse of temporary directories on runners, hardens agent retry validation for
failed runs, and refines Auto Mode agent model options.

---

## Highlights

- **Real-time CLI streaming**: The Go CLI client now connects to the server WebSocket endpoint
  (`/ws`) to stream agent and script output in real time, with graceful fallback to status polling.
- **Notification settings**: Notification enablement and test buttons were moved to the Settings page,
  eliminating automatic permission prompts on first launch.
- **Apple Touch & maskable PWA icons**: Added rounded Apple Touch and maskable icons (`icon-192-maskable.png`,
  `icon-512-maskable.png`, `apple-touch-icon.png`) and updated Apple mobile web app metadata.
- **Agent retry hardening**: Enforced strict validation on the `rerun-agent` endpoint to require a `messageId`
  and only permit retrying failed runs, preserving conversation continuity and prompt parameters.
- **Auto Mode model options**: Excluded GPT-OSS models from Auto Mode Choice B to ensure optimal coding
  and reasoning quality with Claude models.
- **Runner temp dir reuse**: Updated `fs.mkdtemp` in the Go runner to search for and reuse existing empty
  fixed-prefix directories before creating new ones.

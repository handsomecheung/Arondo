# Arondo v0.2.43

**Release Date:** 2026-09-28
**Commits:** 6
**Tag:** v0.2.43

This release introduces optional project selection for sessions, script rerun support on completed and stopped script cards, unread session prioritization in the sidebar, special workspace indicators in the task info bar, 7-day expiration for once cache entries, and CLI command renaming.

---

## Highlights

- **Optional Project Selection**: Creating a new session no longer requires selecting a project or workspace path up front, allowing effortless ad-hoc conversations and tasks.
- **Rerun Completed & Stopped Scripts**: Added a Rerun action to script execution cards in sessions and tasks views, enabling quick re-execution of finished or stopped scripts in-place.
- **Unread Completed Sessions Prioritization**: Sessions with unread completed agent responses are prioritized in the sidebar for quick catch-up.
- **Special Workspace Labels**: The task info bar now clearly indicates no-path, temp-dir, and once session execution contexts.
- **Automated Once Cache Expiry**: Output cache entries generated with `--once` are now automatically expired and cleaned up after seven days.
- **CLI Command Renaming**: Renamed `list-agents` to `get-agents` in the Go CLI for consistency across agent query commands.

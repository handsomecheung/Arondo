# Arondo v0.3.8

**Release Date:** 2026-11-02
**Commits:** 4
**Tag:** v0.3.8

This patch release adds back navigation and previous session highlighting to the Project Page, displays running project-scoped scripts with live logs and stop controls under the Scripts section, prioritizes alternative quota groups within the same agent on Auto Mode lock exhaustion, and fixes file link conversion when rendering agent Markdown output to HTML.

---

## Highlights

- **Back Navigation & Previous Session Highlight**: Navigating from a session to its Project Page now provides a back button to return to the previous session. The session the user navigated from is also visually highlighted in the project's session list.
- **Running Scripts on Project Page**: The Project Page's Scripts section displays running project-scoped scripts inline, complete with real-time status, live streaming output logs, and stop controls.
- **Intra-Agent Quota Group Fallback on Lock Exhaustion**: When Auto Mode is locked to an agent whose primary quota group is exhausted, it prioritizes alternative quota groups within the same agent (such as switching between Gemini and Anthropic/Other models) before falling back to switching agents or failing.
- **Agent Output File Link Rendering**: Fixed file link conversion when rendering agent Markdown output to HTML, properly resolving file paths and file URIs against runner filesystem status to render verified clickable links or diff buttons rather than broken empty links.

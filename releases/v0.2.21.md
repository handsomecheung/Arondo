# Arondo v0.2.21

**Release Date:** 2026-08-20
**Commits:** 5
**Tag:** v0.2.21

Session metadata is leaner after removing stored prompt data, and the Automation
CLI environment file has been renamed for clarity alongside expanded documentation.

---

## Highlights

- **Prompt Removed from Session Metadata**: Prompts are no longer stored in session metadata, reducing storage overhead and keeping session records focused on execution state.
- **Automation CLI Cleanup**: The CLI environment file has been renamed from `env.example` to `arondo.env.example` for clarity, and the CLI now resolves the file consistently.
- **Expanded Documentation**: Added localized READMEs (Japanese, Simplified Chinese, Traditional Chinese) and a detailed usage guide with screenshots.

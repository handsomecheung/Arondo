# Arondo v0.2.26

**Release Date:** 2026-08-26
**Commits:** 5
**Tag:** v0.2.26

This release adds project-scoped agent command configuration, tightens Auto
Mode behavior when automodel routing is active, improves CLI confirmation
handling, and polishes the new session and settings surfaces.

---

## Highlights

- **Project agent commands**: Projects can now define agent commands, with a
  dedicated settings manager and project-level API support.
- **Auto Mode locking**: Auto-selected agents remain locked while automodel
  still chooses among the routed model and effort options.
- **CLI confirmation handling**: CLI send confirmation is now handled through a
  shared prompt helper with updated tests and bundled skill instructions.
- **Settings terminology**: The former Automodel settings section is now
  presented as LLM API Keys with clearer copy around optional key usage.
- **New session alignment**: New session dropdowns now align with the input left
  edge for a cleaner mobile-first composition layout.

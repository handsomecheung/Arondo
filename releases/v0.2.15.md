# Arondo v0.2.15

**Release Date:** 2026-07-27
**Commits:** 12
**Tag:** v0.2.15

OpenCode CLI agent support, Git commit history tracking (Show Commits), multiple file attachments in chat, locked auto-agent selection, Show Stderr logs, and automated temporary directory cleanup. This version broadens agent coverage with the new OpenCode integration, enhances repository visibility with built-in commit diff inspection, and refines chat inputs and workspace management.

---

## Highlights

- **OpenCode CLI Agent Support**: Added support for OpenCode as a fourth concrete agent type, featuring custom command adaptation, remote session list matching for continuity, and switcher dropdown integration.
- **Git Commit History Viewer**: Introduced a "Show Commits" modal in the project panel and session view, allowing users to view the git commit log and inspect individual commit diffs inline via diff2html.
- **Multiple File Attachments**: Upgraded the chat input and submission workflow to support selecting, uploading, and passing multiple file attachments to the agent concurrently.
- **Codex & Auto-Selection Enhancements**: Implemented session-level locking for the auto-selected agent after its first dispatch, exposed Codex in the session header switcher, and integrated reasoning effort configurations.
- **PTY Log & Workspace Improvements**: Added a "Show Stderr" option in the agent card menu to inspect error streams easily, updated timestamps older than today to show full date and time, and introduced background auto-cleaning for temporary workspaces.

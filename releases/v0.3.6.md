# Arondo v0.3.6

**Release Date:** 2026-10-28
**Commits:** 3
**Tag:** v0.3.6

This patch release adds rendered HTML output for CLI commands, displays the model used by each agent run, simplifies completed agent cards, and keeps sidebar session menus in place when tags wrap.

---

## Highlights

- **Rendered HTML Output for CLI Commands**: `send` and `get-messages` now support `--output html`. Agent output is rendered on the server as Markdown with syntax highlighting and cached for reuse. The session HTML endpoint can resolve the latest execution when no message ID is supplied and generate HTML from execution logs when no cached output exists.
- **Agent Run Model Display**: New agent runs, follow-ups, retries, and detached agents record the selected model. Execution cards display that model below the agent name, with wrapping for long names, and hide the status line after successful agent completion.
- **Stable Sidebar Session Menus**: The session three-dot menu stays anchored in the top-right corner when Automation and Once tags wrap onto additional lines.

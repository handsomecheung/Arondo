# Arondo v0.3.7

**Release Date:** 2026-10-29
**Commits:** 4
**Tag:** v0.3.7

This patch release adds quota progress bars to new session dropdowns and per-message Auto Mode selection logs, fixes handling of omitted quota metrics, and prevents Auto Mode from selecting agents with exhausted quota.

---

## Highlights

- **Quota Progress Bars in New Sessions**: The Agent dropdown displays known hourly and weekly quota for the selected Runner. Antigravity quota is shown separately for Gemini, Anthropic & Other, and Gemini 4 Argon, with the same bars in its Model dropdown group headings. Missing quota and API-key billing are labeled explicitly, and colors match the Runners page.
- **Auto Mode Selection Logs**: Each new session, follow-up, and detached agent run using Auto Mode writes a selection trace to its message-specific `.autoagent.log` file. The trace records candidates, quota data and timestamps, filtering, scores, candidate order, and the final selection, including session lock overrides.
- **Reliable Quota Handling**: Omitted quota metrics are treated as unknown. Auto Mode excludes subscription choices with known hourly or weekly quota at or below 2%, including single-choice and session-locked selections. When no eligible choice remains, requests return HTTP 503 without starting an agent, and queued messages remain pending. Quota recovery uses the latest record and requires weekly quota above 2% and hourly quota of at least 15% when known.

# Arondo v0.2.17

**Release Date:** 2026-07-29
**Commits:** 6
**Tag:** v0.2.17

Per-token custom colors and sender avatars on user message cards, a unified getConfirmationButtons helper to prevent modal and test drift, and key fixes for sidebar sorting and task queue visibility.

---

## Highlights

- **Per-Token Colors & Avatars**: Generates a visually distinct color for each access token (stored in `arondo.json` and auto-backfilled). The sender's custom color and name are displayed on user chat, slash command, and todo message cards alongside their avatar.
- **Unified Confirmation Buttons**: Extracted `getConfirmationButtons` in [homeUtils.ts](file:///mnt/coder-workspaces/private-workspace/repos/github/Arondo/lib/homeUtils.ts) as the single source of truth for project readiness warnings, mapping dialog choices dynamically to avoid test drift.
- **Sidebar Sorting Update**: Updated the sidebar session list to sort by last updated time instead of creation time for better relevance.
- **Task Queue Scope Fix**: Fixed an issue where project-scoped tasks with empty session IDs were incorrectly hidden from the Task Queue due to matching the archived-sessions directory.

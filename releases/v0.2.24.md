# Arondo v0.2.24

**Release Date:** 2026-08-25
**Commits:** 4
**Tag:** v0.2.24

This release expands the Go CLI with session history inspection, structured
output formatting, and quota timestamp display, and adds automatic collapsing
of viewed execution cards in the session view.

---

## Highlights

- **CLI `get-messages`**: New subcommand to fetch and print the full conversation
  history of a session, with optional inline log display (`--with-logs`) and
  `--latest` flag to resolve the most recently updated session automatically.
- **CLI `--output` flag**: All subcommands (`send`, `list-agents`, `get-quota`,
  `update-quota`) now accept `--output plain|json` for machine-readable output.
- **Quota timestamp formatting**: `get-quota` now displays human-readable
  timestamps for quota reset times.
- **Collapsed viewed cards**: Execution cards that have already been viewed are
  now collapsed by default in the session timeline to reduce visual clutter,
  with an expand toggle to restore them.

# Arondo v0.3.15

**Release Date:** 2026-11-10
**Commits:** 2
**Tag:** v0.3.15

This patch release adds per-turn effort routing and display across agents using Jev System One decision models, and introduces the `--runner-name` option to `arondo-cli send`.

---

## Highlights

- **Per-Turn Effort Routing**: Ongoing sessions and explicitly selected agents can now dynamically route model effort on each turn using Jev System One decision models across Antigravity, Claude, Codex, and OpenCode.
- **Effort Display Across Agents**: Resolved effort levels and reasoning efforts are displayed across message cards, agent status, and history.
- **Runner Name in CLI**: The `arondo-cli send` command now supports targeting runners by name (`--runner-name`) as an alternative to runner IDs.

# Arondo v0.2.40

**Release Date:** 2026-09-15
**Commits:** 5
**Tag:** v0.2.40

This release adds single-use, optionally cached CLI runs for ephemeral workspaces and makes session messaging and error reporting more reliable.

---

## Highlights

- **Single-use CLI Sessions**: `arondo-cli send --temp-dir --once` creates an ephemeral session that accepts exactly one message, making it well suited to isolated automation tasks.
- **Cached Ephemeral Results**: `--cache on` stores single-use results by prompt hash and returns matching results immediately without starting another agent run.
- **Flexible Todo Workflows**: A session can receive a new message while it has pending Todo messages, so queued work no longer blocks follow-up communication.
- **Accurate Session Errors**: Session error status is now derived from its messages, keeping completed and failed task states consistent after message updates.

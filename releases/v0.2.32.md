# Arondo v0.2.32

**Release Date:** 2026-08-29
**Commits:** 5
**Tag:** v0.2.32

This release adds an admin-controlled Auto Model toggle, isolates session events
and completion notifications to the session creator, improves agent card
navigation, and makes agent file links more robust when paths cannot be verified.

---

## Highlights

- **Auto Model Admin Toggle**: Added an `enableAutomodel` setting in Admin Settings
  so administrators can enable or disable second-stage model and effort routing
  without removing saved provider API keys.
- **Session Event Isolation**: Session creation now records the creator client UUID,
  and WebSocket session events and completion notifications are filtered so only
  the originating client receives them.
- **Agent Output Navigation**: Double-clicking or expanding execution and message
  cards now scrolls the card back to the top, improving review of long agent outputs
  on mobile and desktop.
- **Unverifiable File Link Handling**: Agent file links that cannot be verified are
  rendered with a distinct unavailable state, and cached agent HTML is refreshed
  when link verification changes.
- **New Session Menu Polish**: Increased the new-session dropdown max height so
  agent and option menus are easier to use on constrained screens.

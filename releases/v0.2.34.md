# Arondo v0.2.34

**Release Date:** 2026-09-03
**Commits:** 6
**Tag:** v0.2.34

This release introduces drag-and-drop file upload support in the chat interface, an agent output streaming (`--follow`) flag to the CLI `get-messages` command, a streamlined sidebar integrating runner and project filters directly, and improved temp directory isolation for running sessions.

---

## Highlights

- **Chat Drag-and-Drop Uploads**: Upload files effortlessly by dragging and dropping them into the chat input area, storing them under session directories with timestamp prefixes.
- **CLI Real-Time Output Streaming**: Added `--follow` (`-f`) flag to `arondo-cli get-messages` to stream running agent logs and outputs in real time.
- **Unified Sidebar Navigation**: Replaced the separate Recent Sessions tab by integrating runner and project filters directly into the sidebar for faster switching.
- **Temp Directory Safety**: Prevents reusing temporary directories that have active running sessions on the runner.
- **Modular Model Configurations**: Extracted agent model configs into dedicated modules with clearer model descriptions.

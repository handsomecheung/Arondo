# Arondo v0.3.23

**Release Date:** 2026-11-24
**Commits:** 2
**Tag:** v0.3.23

This patch release adds a Jev-powered check that catches accidentally unfinished messages before they are sent, and makes session scripts run in the runner's default shell so zsh aliases are available.

---

## Highlights

- **Unfinished Message Check**: Before a message is submitted, Jev checks whether it looks accidentally incomplete and shows a confirmation modal so you can keep editing or send it anyway.
- **Default Shell for Scripts**: Scripts run through the runner's `$SHELL` instead of always using `bash`. When the shell is zsh, it is started interactively so aliases from `.zshrc` are loaded.

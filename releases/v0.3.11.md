# Arondo v0.3.11

**Release Date:** 2026-11-05
**Commits:** 3
**Tag:** v0.3.11

This patch release adds OpenCode free model groups and inline model selection in the session agent menu, and keeps sidebar runner and project filters in the URL so they survive refresh and navigation.

---

## Highlights

- **OpenCode Free Model Groups**: Admin Settings and model dropdowns now separate OpenCode **Go / Pay-as-you-go** models from **Free** models. The Free list is editable through `opencode.freeModels`, and existing `-free` or `big-pickle` entries are grouped automatically. Free models keep their `opencode-go/` prefix, and the Free group has no Go quota bars.
- **Inline Model Selection in the Agent Menu**: Each agent row in the session agent switch menu now expands in place to show its models, with Default listed first. OpenCode includes the Free group, and Antigravity keeps its three model groups. Choosing a model saves it for subsequent runs of the session.
- **Persistent Sidebar Filters**: The sidebar runner and project filters are mirrored to the URL query (`?runner=`, `?project=`), so they survive refresh and back/forward navigation. Stale IDs that no longer exist are cleared automatically.

# Arondo v0.3.22

**Release Date:** 2026-11-22
**Commits:** 3
**Tag:** v0.3.22

This patch release improves runner path verification so request errors and timeouts are distinguished from missing directories, makes Agent Commands available in the New Session command menu, and simplifies the README while preserving detailed specifications in the project context documentation.

---

## Highlights

- **Reliable Runner Path Verification**: Runner request failures and timeouts no longer report a session directory as missing. Follow-up messages, detached agents, and session scripts return a verification error with HTTP 503 when a path check fails, while confirmed missing paths still return HTTP 400. Project listings preserve entries when runner path checks fail.
- **Agent Commands on the New Session Page**: Typing `/` or a partial command trigger shows matching Agent Commands when creating a session. Session-only commands (`/new`, `/rename`, and `/delete`) stay hidden until an existing session is selected.
- **Simplified Project Documentation**: The README focuses on the basic workflow, core features, and setup, with detailed specifications retained in `AGENTS-CONTEXT.md`.

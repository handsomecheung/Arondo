# Arondo v0.3.13

**Release Date:** 2026-11-06
**Commits:** 3
**Tag:** v0.3.13

This patch release makes word wrap the default in the Show Changes and file diff views, fixes diff line overflow and right margin when wrapping is enabled, and ignores local `.env` and `local` files in the `scripts` directory.

---

## Highlights

- **Word Wrap by Default in Diffs**: Show Changes, single-file diff modals, and diff routes now wrap long lines by default. The toggle is still available to turn wrapping off.
- **Diff Line Overflow Fix**: Long lines in wrapped diffs no longer overflow or break the right margin of the diff view.

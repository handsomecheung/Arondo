# Arondo v0.3.3

**Release Date:** 2026-10-25
**Commits:** 4
**Tag:** v0.3.3

This patch release adds support for Gemini 4 Argon quota tracking in Antigravity, introduces optional model selection when starting new sessions, brings swipe-to-archive gestures with undo in the sidebar, and updates default agent model presets.

---

## Highlights

- **Gemini 4 Argon Quota Support in Antigravity**: Antigravity runners now extract Gemini 4 Argon weekly quota data, supported across AutoAgent selection (Choice E), LLM and regex quota extraction, and the Runners dashboard.
- **Optional Model Selection for New Sessions**: Explicitly choose the model when starting a session with Antigravity, Claude, or Codex directly from the new session screen.
- **Swipe-to-Archive with Undo**: Sessions in the sidebar can now be archived using a swipe gesture, complete with a 3-second undo toast.
- **Updated Agent Model Presets**: Default agent model configurations and fallbacks have been updated across Antigravity, Claude, and Codex.

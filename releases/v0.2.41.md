# Arondo v0.2.41

**Release Date:** 2026-09-16
**Commits:** 3
**Tag:** v0.2.41

This release introduces agent analysis for script outputs, enhances path handling when running scripts via the quick-exec menu, and ensures slash-prefixed messages are accurately rendered.

---

## Highlights

- **Analyze Script Output with Agent**: Added an "Analyze with Agent" action to the three-dot menu on script execution cards in both Session and Tasks views, allowing quick delegation of output or error diagnosis to an AI agent.
- **Accurate Slash-Prefixed Message Rendering**: Regular chat messages starting with `/` (such as URL endpoints or filesystem paths like `/api/...` and `/user/...`) now correctly render as standard user messages rather than command execution cards unless they match a valid agent command.
- **Executable Path Prefixing for Quick-Exec**: Relative paths selected from the file browser via the `!` trigger menu are now automatically prefixed with `./`, preventing execution failures when running scripts directly from the chat prompt.

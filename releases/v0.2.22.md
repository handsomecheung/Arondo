# Arondo v0.2.22

**Release Date:** 2026-08-20
**Commits:** 8
**Tag:** v0.2.22

This release adds independent review and side-question agent commands, makes it
easier to send work while a project is busy, and improves agent selection and
session recovery reliability.

---

## Highlights

- **Detached Agent Commands**: Use `/review` to inspect the working tree or `/btw` to ask a side question in a separate agent context without interrupting the current session.
- **More Flexible Session Sending**: New sessions can be force-sent while an agent is running, and the CLI now includes a `send` subcommand for automation workflows.
- **Agent Skill Installer**: Install the Arondo agent skill directly from the CLI.
- **Improved Reliability**: Fixed Antigravity conversation ID recovery, Auto Mode selection for API-billed agents, and runner-associated project navigation.

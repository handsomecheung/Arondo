# Arondo v0.2.35

**Release Date:** 2026-09-03
**Commits:** 4
**Tag:** v0.2.35

This release improves runner quota monitoring with targeted refresh actions, preserves streamed agent output more reliably, and makes the quota display reflect Auto Mode's selection score.

---

## Highlights

- **Targeted Quota Refresh**: Authorized users can request a quota refresh for individual runners instead of refreshing all runner data.
- **Auto Mode Score Visualization**: Quota bars now use colors derived from Auto Mode's scoring, making the preferred runner easier to identify at a glance.
- **Reliable Streamed Output**: Agent output received in multiple streamed chunks is preserved correctly.

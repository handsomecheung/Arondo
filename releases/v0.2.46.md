# Arondo v0.2.46

**Release Date:** 2026-09-30
**Commits:** 7
**Tag:** v0.2.46

This release improves mobile session creation, strengthens Web Push subscriber isolation, and keeps Runner interaction detection compatible with recent Codex CLI behavior.

---

## Highlights

- **Mobile Input Visibility**: New-session suggestions and dialogs remain above the on-screen keyboard, making session creation more reliable on mobile devices.
- **Isolated Web Push Delivery**: Push subscriptions are now targeted by the authenticated client-token UUID, preventing notifications from being delivered across users.
- **Current Codex CLI Support**: Runner quota parsing and startup-modal handling support Codex CLI v0.158.0, while sudo password prompts are surfaced as input waits.

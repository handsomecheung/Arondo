# Arondo v0.2.27

**Release Date:** 2026-08-27
**Commits:** 7
**Tag:** v0.2.27

This release improves the mobile chat experience, refines temporary-project
handling, strengthens Auto Mode quota preservation, and makes detached agent
workflows and markdown file links more reliable.

---

## Highlights

- **Rotating chat tips**: The composer now presents rotating hints that make
  key chat actions easier to discover.
- **Temporary project cleanup**: Temporary-directory projects are hidden from
  the runners view, keeping operational lists focused on persistent work.
- **Detached workflow reliability**: Detached agent commands now use the
  messages API and stay out of CLI message history.
- **Absolute file links**: Markdown output can link verified absolute file
  paths directly to the remote file browser.

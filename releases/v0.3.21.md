# Arondo v0.3.21

**Release Date:** 2026-11-20
**Commits:** 3
**Tag:** v0.3.21

This patch release adds chat draft persistence for the Gen Main Agent, improves draft clearing and automatic restoration on delivery failure across Session and Gen chats, and aligns Enter and newline keyboard behavior between desktop and mobile inputs.

---

## Highlights

- **Gen Chat Draft Persistence**: Unsent chat drafts in the Gen Main Agent view are now automatically saved to `localStorage` (`arondo:chat-draft:gen`) and restored across page reloads and navigation.
- **Reliable Draft Clearing & Failure Recovery**: Chat drafts in both Session and Gen views now clear only upon successful delivery (HTTP 200) and automatically restore the user's input text if message submission or session creation fails.
- **Consistent Desktop & Mobile Enter Key Behavior**: Aligned keyboard submission behavior across Session and Gen chat inputs—`Enter` sends on desktop while `Shift+Enter` or `Ctrl+Enter` / `Meta+Enter` inserts a newline, and standalone `Enter` on mobile devices inserts a newline to prevent accidental sends.

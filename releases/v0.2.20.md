# Arondo v0.2.20

**Release Date:** 2026-08-19
**Commits:** 9
**Tag:** v0.2.20

Automation is now available through a standalone Node.js CLI, alongside smoother
chat and scheduled-follow-up workflows while project scripts run.

---

## Highlights

- **Node Automation CLI**: Added the `arondo` command-line client for creating and monitoring automation sessions, sending follow-ups, running project scripts, and inspecting runners. It supports environment-based configuration, JSON output, and a positional prompt for concise invocation.
- **Chat During Script Execution**: Session chat remains available while scripts are running. Follow-up messages can be scheduled and automatically dispatched after the session becomes idle.
- **Script and Command Management**: Added direct menu actions for managing project scripts and custom agent commands.
- **Reliable Quota Handling**: Empty or malformed agent quota files now resolve safely instead of disrupting quota aggregation.

# Arondo v0.2.45

**Release Date:** 2026-09-29
**Commits:** 7
**Tag:** v0.2.45

This release improves task notifications and execution monitoring, with clearer task context, less intrusive notification behavior, and Linux support for detecting scripts that are waiting for terminal input.

---

## Highlights

- **Focused Task Notifications**: Notifications include useful task context while avoiding redundant alerts when the app is active, for short-lived tasks, or when temporary-session notifications are disabled.
- **Script Input-Wait Detection**: Linux Runners detect when a script is blocked waiting for terminal input, making interactive task state visible to the workspace.
- **Execution Context Improvements**: Task cards and task views present command and prompt context more consistently, including rerun handling.

# Arondo v0.2.38

**Release Date:** 2026-09-06
**Commits:** 3
**Tag:** v0.2.38

This release separates runner-installed agent availability from persisted quota identities and makes unknown quota reset times clearer in the Runners dashboard.

---

## Highlights

- **Reliable Agent Availability**: Runner-reported installed agent binaries are now tracked separately from quota account references, so execution availability and quota refreshes use the correct source of truth.
- **Clear Unknown Quotas**: Quota bars whose reset time is unavailable are shown in gray, making incomplete quota information easy to distinguish from scored availability.

# Arondo v0.2.39

**Release Date:** 2026-09-11
**Commits:** 4
**Tag:** v0.2.39

This release adds project listing to the CLI, refines sidebar project filtering, preserves session timestamps across status and pin changes, and improves the archived sessions navigation workflow.

---

## Highlights

- **CLI `get-projects` Command**: Added a new subcommand to `arondo-cli` allowing users to quickly list all accessible projects and their associated runner and repository path in plain text or JSON.
- **Sidebar Project Filter Optimization**: Projects without active sessions are now excluded from the sidebar project filter chips, keeping the workspace view focused on active projects.
- **Preserve Session Timestamps**: Operations like pinning/unpinning and archiving/unarchiving now preserve the session's `updatedAt` timestamp, ensuring session ordering remains consistent with conversation activity.
- **Persistent Archived View Context**: Unarchiving a session now maintains the view on the archived list instead of abruptly resetting back to the active sessions view.

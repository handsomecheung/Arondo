# Arondo v0.3.19

**Release Date:** 2026-11-18
**Commits:** 4
**Tag:** v0.3.19

This patch release adds Auto thinking effort support for Antigravity, aligns agent dropdown ordering with the Runners dashboard, improves task cancellation with full process-tree termination and SIGKILL escalation, and displays runner versions directly on runner cards.

---

## Highlights

- **Auto Thinking Effort**: Renamed the unset thinking effort option from `Default` to `Auto`, added `Auto` support for Antigravity model families with two or more variants (defaulting to `Auto` and falling back to `Medium` when automodel is unavailable).
- **Consistent Agent Menu Ordering**: Ordered the agent dropdown menu to match the Runners page (Claude Code, Antigravity CLI, OpenCode, Codex, Pi), with API Key billed agents listed last.
- **Reliable Task Cancellation**: Canceling a running task now terminates the entire process tree and escalates from `SIGTERM` to `SIGKILL` if the process does not exit promptly.
- **Runner Version Visibility**: Runner cards on the Runners dashboard now display the Runner version directly without requiring expansion.

# Arondo v0.3.9

**Release Date:** 2026-11-04
**Commits:** 4
**Tag:** v0.3.9

This patch release adds OpenCode Go quota monitoring, configurable models, and Auto Mode support, displays quota when switching a session's agent, restores admin access to projects across clients, and simplifies local development setup.

---

## Highlights

- **OpenCode Go Support**: Runners collect 5-hour, weekly, and monthly Go quota through the signed-in OpenCode v2 CLI. The Runners page and Agent dropdown display the remaining quota and reset times. Admin Settings adds an OpenCode model list and default, with session model selections passed to fresh runs and resumes and attached `#variant` suffixes preserved.
- **Quota-Aware OpenCode Auto Mode**: Auto Mode considers OpenCode only when the execution Runner has a linked Go quota record with all three windows known and above 2%. Model choices are restricted to `opencode-go/`, and quota retries account for monthly limits and wait for the last blocking window to reset.
- **Quota in the Session Agent Menu**: Switching an existing session's agent now shows the selected Runner's quota bars, quota groups, and loading or unavailable labels in the shared Agent dropdown. The menu scrolls within the available viewport.
- **Admin Project Visibility**: Admins can list projects across clients, allowing them to open projects associated with sessions they can already access. Regular users retain per-client project isolation.
- **Simpler Development Setup**: A single `scripts/run.runner.sh` replaces the numbered runner scripts. A new `scripts/sample.env` and updated README explain local configuration and token setup, while the server startup script uses configured quota and automodel settings instead of hardcoded overrides.

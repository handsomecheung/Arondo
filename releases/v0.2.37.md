# Arondo v0.2.37

**Release Date:** 2026-09-06
**Commits:** 5
**Tag:** v0.2.37

This release adds deliberate runner disconnection, makes temporary-session retention configurable, and improves recovery from failed script runs.

---

## Highlights

- **Runner Disconnect Control**: Administrators can disconnect a connected runner from the Runners dashboard. The runner acknowledges the request before stopping, and any active tasks are stopped.
- **Configurable Temporary Retention**: Configure how many hours temporary sessions and projects are retained, with a 72-hour default and an environment-variable override.
- **In-place Failed Script Retry**: Failed session and project script cards can be retried in their existing task slot, clearing the prior failure state and log before the restart.

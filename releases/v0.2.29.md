# Arondo v0.2.29

**Release Date:** 2026-08-27
**Commits:** 4
**Tag:** v0.2.29

This release adds a setting to toggle the visibility of temporary-directory automation
projects and sessions, streamlines the sidebar navigation by removing the legacy
projects view mode, and improves integration test isolation for events and configuration.

---

## Highlights

- **Temporary projects & sessions toggle**: A new setting allows showing or hiding
  temporary automation sessions and projects created with temporary directories across
  the sidebar, Runners, and Tasks pages.
- **Streamlined sidebar**: Removed the legacy projects list mode from the sidebar to
  focus entirely on session navigation with project filter chips.
- **Client event & notification isolation tests**: Added automated test coverage
  verifying that WebSocket events and push notifications are strictly isolated to authorized
  client devices.
- **Test environment isolation**: Playwright integration tests now isolate the `HOME`
  directory to protect local agent configuration files during test runs.

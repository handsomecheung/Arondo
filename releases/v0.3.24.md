# Arondo v0.3.24

**Release Date:** 2026-11-26
**Commits:** 5
**Tag:** v0.3.24

This patch release adds global agent skill installation across runners from Admin Settings, introduces Read Aloud text-to-speech for agent outputs using Google Cloud TTS with per-session audio caching, and refactors session status derivation with a new `needs_attention` state.

---

## Highlights

- **Skill Installation Across Runners**: Admin Settings now features a Skills management page (`/admin/settings/skills`) to install skills globally across connected runners and supported agents (`codex`, `claude-code`, `antigravity-cli`, `opencode`, `pi`), with per-job file persistence and automatic duplicate skipping.
- **Read Aloud (Text-to-Speech)**: Agent output cards now include a "Read Aloud" action in the three-dot menu, powered by Google Cloud Text-to-Speech (Chirp 3: HD voice). Generated speech is cached per session on disk for instant replay.
- **Derived Session Status & `needs_attention`**: Session status is now reliably derived from task initiation order and active runner tasks, introducing a distinct `needs_attention` state for failed runs or sessions requiring intervention.

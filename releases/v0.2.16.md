# Arondo v0.2.16

**Release Date:** 2026-07-28
**Commits:** 12
**Tag:** v0.2.16

Scheduled sending for chat messages and drafts, a "!" quick-exec menu that learns your most-used commands and lets you run any file directly, and a runner filter in the sidebar. This release rounds out the todo-message system with explicit "Send Later" / "Send When Clean" / "Schedule Send" options and fixes several rough edges in the task queue and project-readiness flow.

---

## Highlights

- **Scheduled & Deferred Sending**: The chat input's attach button is now a "+" popup menu offering "Upload File", "Send Later" (queue for manual send), "Send When Clean" (auto-send once the working tree is clean), and "Schedule Send" (pick a future date/time). All reuse the existing todo-message/draft-trigger plumbing, and a shared `ScheduleDateTimeInputs` date+time picker backs draft creation, the chat scheduler, and the todo card's change-trigger menu.
- **Quick-Exec Command History & File Picker**: The "!" chat trigger now records every command it runs (predefined or ad-hoc) to a per-project history file, surfacing your 5 most-used commands in the menu. A new "Select…" entry opens the file browser to run a picked file directly as a shell command.
- **Runner Filter in Sidebar**: When sessions span multiple runners, horizontally scrollable runner filter chips appear alongside the existing project filter chips.
- **Codex Global Rules Sync**: Global agent rules now also sync to `~/.codex/AGENTS.md` on runners, alongside the existing Gemini and Claude targets.
- **Task Queue & Readiness Fixes**: The "Send now anyway" button is hidden when a running agent already blocks the session (the server always rejects it in that case); the Task Queue's delete button now only shows for project-scoped tasks; completed tasks are removed from the queue as soon as their session is archived; and opening a URL for a nonexistent session no longer silently falls back to the first session in the list.

# Arondo v0.2.44

**Release Date:** 2026-09-29
**Commits:** 2
**Tag:** v0.2.44

This release adds server-driven Web Push notifications, including device-level controls and VAPID configuration for administrators.

---

## Highlights

- **Server-Driven Web Push**: Receive notifications when background agent work completes, with subscriptions managed per device and delivery handled by the server.
- **Device Notification Controls**: Enable, test, or disable Web Push from Settings without exposing server-wide configuration to regular users.
- **Admin VAPID Configuration**: Configure the VAPID contact email in Admin Settings; server-level notification credentials and settings remain administrator-only.

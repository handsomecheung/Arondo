# Arondo v0.3.12

**Release Date:** 2026-11-05
**Commits:** 6
**Tag:** v0.3.12

This patch release splits Admin Settings into dedicated section subpages with unified save actions and restored styling, syncs global agent rules to OpenCode AGENTS.md, adds Jev tags for decision sessions in the sidebar, disambiguates todo message triggers into "When Clean" and "After Run", and restricts OpenCode model menus to free models when Go subscriptions are unavailable.

---

## Highlights

- **Admin Settings Modularization & Unified Save**: Reorganized Admin Settings from a monolithic page into dedicated section subpages (`/admin/settings/sessions-and-files`, `agent-models`, `automodel`, `web-push`, `agent-commands`, `global-rules`, `system-tokens`, `runner-tokens`, `runner-access`). Save and Cancel behaviors are unified across forms, with deferred token creation and renamed/revoked states properly preserved during editing.
- **OpenCode Free Model Filtering & State Reporting**: On runners without an active Go subscription (`Plan: "Free"` or `unauthenticated`), model dropdown menus now present only free models under `opencode/`. Unconfigured OpenCode instances without credentials are also reported as Free rather than API-key billed.
- **Global Rules Sync to OpenCode**: Runners now sync global agent rules to `~/.config/opencode/AGENTS.md` alongside Gemini, Claude, and Codex configuration files.
- **Sidebar Jev Session Tag**: Decision sessions powered by Jev System One are now badged with a dedicated `Jev` tag in the sidebar alongside existing `Automation` and `Once` tags.
- **Disambiguated Todo Auto Triggers**: Clarified auto triggers for scheduled todo messages by separating them into explicit "When Clean" (waits for codebase working tree to be clean) and "After Run" (waits for the current agent run to finish) triggers.

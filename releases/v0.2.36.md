# Arondo v0.2.36

**Release Date:** 2026-09-04
**Commits:** 4
**Tag:** v0.2.36

This release updates Codex quota monitoring for its current status display,
improves management of completed script cards, and refines the mobile session
workflow.

---

## Highlights

- **Current Codex quota status support**: Codex's five-hour and weekly limits,
  including their reset times, are now parsed from the latest `/status` layout
  and shown in runner and CLI quota information.
- **Completed script cleanup**: Completed session script cards can now be
  deleted. Their associated messages are hidden from the session timeline while
  preserving the underlying record for safe handling.
- **Deliberate quick-script sends**: Choosing a quick script now waits for the
  message to be sent, preventing accidental execution while composing a prompt.
- **Relevant runner filters**: The sidebar runner filter now lists only runners
  that have sessions.

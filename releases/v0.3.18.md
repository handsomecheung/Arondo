# Arondo v0.3.18

**Release Date:** 2026-11-16
**Commits:** 5
**Tag:** v0.3.18

This patch release adds Gemini 4 Hydrogen and Orchestrator to the default Antigravity preset models, disables session inputs and selections when agents or runners are unavailable, skips dynamic effort routing when effort is explicitly configured, and improves OpenCode quota guidance.

---

## Highlights

- **Antigravity Preset Models**: Added Gemini 4 Hydrogen and Orchestrator to default Antigravity presets across agent models and Auto Agent configuration.
- **Availability Guardrails**: Session input, agent selection, and runner selection are now disabled with clear visual feedback when no agents or runners are connected.
- **Dynamic Effort Bypass**: Dynamic thinking effort routing is skipped when both a model and thinking effort level are explicitly selected.
- **OpenCode Quota Guidance**: The Runners dashboard now displays actionable Console login guidance when OpenCode quota cannot be retrieved.

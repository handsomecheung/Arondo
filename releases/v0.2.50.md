# Arondo v0.2.50

**Release Date:** 2026-10-11
**Commits:** 2
**Tag:** v0.2.50

This release improves project directory selection in the New Session file explorer modal and fixes middle-truncated path display styling.

---

## Highlights

- **Interactive Directory Selection in New Session**: Users can now select and highlight directories in the File Explorer modal, double-click to navigate, and confirm directory selection directly into the project repository path.
- **Accurate Runner Directory Tracking**: Fixed an issue where `repoPath` was prematurely cleared when existing projects didn't match, ensuring `repoPath` only resets when changing runners.
- **Gapless Path Truncation**: Eliminated unwanted spacing between prefix and suffix elements in middle-truncated project path headers.

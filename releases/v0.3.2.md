# Arondo v0.3.2

**Release Date:** 2026-10-24
**Commits:** 5
**Tag:** v0.3.2

This patch release improves agent failure handling and quota extraction, makes recently used runners easier to find, and strengthens Auto Mode regression coverage.

---

## Highlights

- **Jev-Powered Agent Failure Classification**: Agent failures are now classified with Jev, improving how Arondo identifies and presents actionable failure states.
- **Recently Used Runners First**: Runner lists are ordered by each user's recent usage, making frequently used machines quicker to select.
- **More Reliable Antigravity Quota Extraction**: The Runner preserves the initial tmux pane's plan and account information when extracting Antigravity quota data.

# Arondo v0.2.14

**Release Date:** 2026-07-26
**Commits:** 13
**Tag:** v0.2.14

Codex CLI support, unified runtime configuration, configurable hidden-file browsing, cleaner Settings controls, separate agent stdout/stderr logs, and stopped-task deletion. This version expands agent coverage with Codex resume and quota tracking, consolidates runtime JSON files, and tightens task/log handling across the UI and runner.

---

## Highlights

- **Codex CLI Agent Support**: Added Codex as a supported agent with `codex exec`, session resume using stored Codex session IDs, quota/status collection via tmux, and quota-aware auto-selection alongside Antigravity and Claude.
- **Unified Runtime Configuration**: Replaced separate token/settings storage with `~/.arondo/arondo.json`, and unified agent conversation mappings under `~/.arondo/agent-sessions.json` for Antigravity and Codex.
- **File Browser & Settings Updates**: Added an admin-controlled "Show hidden files" setting for runner directory listings, grouped session/file controls in Settings, and made session archive days auto-save after edits.
- **Task & Log Improvements**: Added deletion for stopped retained tasks, split piped agent stdout and stderr into separate log files, and rendered agent Markdown soft line breaks more faithfully.
- **Authentication UX Cleanup**: Moved token reset out of Settings and into the sidebar as a Log Out action with confirmation, while simplifying page title metadata and cleaning up lint warnings.

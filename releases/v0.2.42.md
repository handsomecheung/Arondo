# Arondo v0.2.42

**Release Date:** 2026-09-28
**Commits:** 4
**Tag:** v0.2.42

This release improves Antigravity quota parsing, derives active session scripts from their message lifecycle, and enables file-browser word wrap by default.

---

## Highlights

- **Reliable Active Script State**: Active session scripts are now derived from unmatched `script-run` messages instead of a separate `runningScripts` session field, keeping script state consistent across persistence and completion handling.
- **Updated Antigravity Quota Parsing**: The runner now recognizes the latest multi-line `agy` quota usage format, preserving the remaining percentage when the refresh time is reported separately.
- **Readable File Browser by Default**: Word wrap is enabled by default in the Remote File Browser while remaining available as a user-controlled toggle.

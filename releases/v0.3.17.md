# Arondo v0.3.17

**Release Date:** 2026-11-12
**Commits:** 7
**Tag:** v0.3.17

This patch release introduces the experimental Gen main agent, adds model-specific thinking effort controls, and improves Gen session continuity, client isolation, and integration test reliability.

---

## Highlights

- **Experimental Gen Main Agent**: The new Gen chat interface infers the target project, delegates tasks through Auto Mode, maintains compacted conversation memory, and reports results with completion notifications.
- **Gen Session Continuity**: Related requests reuse the latest sub-agent session for the target repository, even when other repositories were queried in between. Sub-agent cards show the session ID and turn number.
- **Client Isolation**: Gen conversations, memory, sub-agent sessions, and runtime state are isolated per client.
- **Thinking Effort Controls**: New Session and session header selectors expose model-specific effort choices, with effort controls kept above the scrolling model list in the header popup.

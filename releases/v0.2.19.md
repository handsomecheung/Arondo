# Arondo v0.2.19

**Release Date:** 2026-08-13
**Commits:** 16
**Tag:** v0.2.19

More reliable quota-aware agent selection, streamlined recent-session and mobile controls, and the ability to run `!` scripts while opening a new session.

---

## Highlights

- **Quota-Aware Auto Selection**: Auto mode now prefers agents with known subscription quota data, falls back to unknown subscription quotas only when needed, and considers API-key billed accounts last. This avoids treating missing quota data or API billing as exhausted capacity.
- **Clearer Quota Reporting**: Corrected Antigravity quota parsing, recognizes API-key billing, and shows an explicit unknown state whenever quota data is unavailable.
- **New-Session Quick Scripts**: Project scripts and ad-hoc `!` commands can now be run directly from the new-session composer once a runner and repository path are selected.
- **Recent Sessions UI**: The sidebar now emphasizes recent sessions with an archived-sessions hint, removes the separate Projects tab and project metadata card, and improves mobile placement and controls for session and task menus.

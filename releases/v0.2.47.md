# Arondo v0.2.47

**Release Date:** 2026-10-01
**Commits:** 16
**Tag:** v0.2.47

This release introduces automated agent quota retry workflows with centralized maintenance scheduling, adds ad-hoc project script running and command history, enables CLI active-session inspection, supports rerunning stopped agent tasks, and surfaces script input waits in the task queue.

---

## Highlights

- **Centralized Maintenance & Periodic Jobs**: Background maintenance is consolidated into a single coordinated loop (`server.ts` / `lib/maintenance.ts`), running quota error retries, scheduled todo dispatching, quota aggregation, and expired task pruning.
- **Automated Quota Error Retries**: Sessions failing due to agent quota limits are automatically detected and scheduled for retry at quota reset time (+5 minutes) once freshness is confirmed.
- **Project-Scoped Script Runner & Execution History**: Ad-hoc commands (`!`), command execution history, and picked files can now be executed across projects without needing dedicated session setups.
- **CLI Session Management**: Added `get-sessions` subcommand to the Arondo CLI to query and inspect active sessions directly.
- **Rerun Stopped Agent Tasks**: Users can now retry and rerun stopped agent runs in addition to failed tasks.
- **Script Input-Wait Visibility**: The global task queue badge highlights tasks waiting on interactive terminal input.

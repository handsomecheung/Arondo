# Arondo v0.2.48

**Release Date:** 2026-10-05
**Commits:** 7
**Tag:** v0.2.48

This release introduces full-text search across session messages and execution logs with runner/project filtering, adds preview and download capabilities for chat attachments, validates runner workspace paths to prevent invalid operations on deleted paths, and establishes an automated startup data migration framework.

---

## Highlights

- **Full-Text Message & Execution Log Search**: Search across past session messages and stdout/stderr execution logs with runner and project filters, with snippet highlighting and direct navigation.
- **Chat Attachment Previews & Downloads**: Uploaded images and files attached to messages can now be previewed inline and downloaded directly from chat cards.
- **Runner Path Validation & Missing Directory Handling**: Automatically detects deleted repository paths on runners via `fs.infos` and the path-status API, disabling message input and project navigation to prevent orphaned task runs.
- **Automated Startup Data Migrations**: Added a server-side startup migration framework to manage data and log format upgrades seamlessly on boot.
- **Responsive Middle-Truncated Project Paths**: Project paths in the ProjectPanel header now use middle truncation with clickable links, maintaining path context while conserving space on mobile and narrow screens.

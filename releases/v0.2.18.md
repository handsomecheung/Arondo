# Arondo v0.2.18

**Release Date:** 2026-08-05
**Commits:** 5
**Tag:** v0.2.18

Detection of individual quota errors for Antigravity (agy), exemption of pinned sessions from auto-archiving, task and todo-message filtering for hidden projects, and corresponding project documentation updates.

---

## Highlights

- **Agy Individual Quota Detection**: Added detection for individual quota limits and subscription warnings for the `antigravity` agent type by scanning both stdout and stderr logs.
- **Pinned Sessions Archive Exemption**: Prevented pinned sessions from being auto-archived when they exceed the stale archive age threshold.
- **Hidden Project Task Filtering**: Tasks and todo-messages belonging to hidden projects are now automatically hidden from the active task queue API endpoints and frontend Tasks view.
- **Documentation Updates**: Updated `README.md` and `AGENTS-CONTEXT.md` to document the new task filtering, pinned session archive exemption, and agent quota detection behaviors.

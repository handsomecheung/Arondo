# Arondo v0.3.20

**Release Date:** 2026-11-20
**Commits:** 4
**Tag:** v0.3.20

This patch release adds opt-in runner self-updates with preflight checks and atomic binary replacement, configurable runner update notices and version reporting with an Admin Settings interface, a runner connection check mode, and graceful runner shutdown with descriptive reasons.

---

## Highlights

- **Opt-in Runner Self-Updates**: Added support for runner self-updates via `--auto-update=true`. The runner downloads new releases, preflights the binary with `--version` and `--check-connection`, waits for active tasks to finish, and atomically replaces the binary with automatic backup and rollback on exec failure.
- **Configurable Runner Update Notices**: Runners now report their version on connect and the server compares it against the server version. Administrators can configure custom download URL templates in Admin Settings (`/admin/settings/runner-updates`), and outdated runners receive update notices.
- **Runner Connection Check Mode**: Added `--check-connection` to the runner binary to test authenticated WebSocket connectivity and token validity via ping/pong with a 10-second timeout, without registering or binding runner tokens.
- **Graceful Runner Shutdown**: Replaced runner connections (when another runner connects with the same token) and admin disconnects now send explicit `runner.shutdown` messages with descriptive reasons, terminating the runner cleanly without reconnect loops.

# Arondo v0.3.4

**Release Date:** 2026-10-26
**Commits:** 4
**Tag:** v0.3.4

This patch release improves Auto Mode session continuity, widens session execution cards on larger screens, fixes Agent Command prompt resolution for CLI and API requests, and resolves TypeScript errors that blocked production builds.

---

## Highlights

- **More Reliable Auto Mode Sessions**: Startup reconciliation now skips recently updated sessions and sessions active in the current server process. New Auto Mode sessions persist their selected agent and model together with session creation. Follow-ups use the saved model and can recover the previous agent and Antigravity quota group from agent-run history.
- **Wider Session Cards on Larger Screens**: Execution cards expand at tablet and desktop breakpoints, providing more room for agent output and script logs.
- **Agent Commands for CLI and API Requests**: Matching slash commands are expanded on the server for new sessions, drafts, follow-ups, and queued messages. Project commands take priority over default commands, while history preserves the original message and explicitly supplied prompts remain intact.
- **Production Build Type Fixes**: Remove an invalid model lookup on agent-run messages and update the model selection test fixture to match the current Runner type.

# Arondo v0.2.31

**Release Date:** 2026-08-28
**Commits:** 4
**Tag:** v0.2.31

This release separates user settings and admin settings pages, adds monochrome PWA icons
and updated notification badges, enhances CLI execution logs to display agent commands,
and excludes pending user-todo messages from CLI message queries.

---

## Highlights

- **User and Admin Settings Separation**: Split Settings into dedicated User Settings (`/settings`)
  and Admin Settings (`/admin/settings`) pages. User Settings provides notification controls,
  push test triggers, and client preferences, while administrative settings (Runner Tokens, Client Tokens,
  Global Agent Rules, Auto Model API keys, and Session Archive duration) are secured under Admin Settings.
- **PWA Notification Badges & Monochrome Icons**: Added monochrome transparent icon assets
  (`icon-transparent-192.png`) and updated notification badges (`badge.png`, `badge-96.png`) for native
  OS notification tray styling and web app manifest compliance.
- **CLI Agent Command Logging**: The `arondo-cli send` command now prints the executed agent command
  in the execution logs prior to streaming output, and the CLI codebase has been modularized into separate
  subsystem files (`agents.go`, `messages.go`, `quota.go`, `ws.go`).
- **CLI Message Filtering**: Updated `get-messages` in the CLI to filter out draft and pending `user-todo`
  messages so that only actual session timeline messages are returned.

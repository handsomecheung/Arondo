# Arondo v0.3.14

**Release Date:** 2026-11-07
**Commits:** 2
**Tag:** v0.3.14

This patch release adds per-agent exclusion from Auto Mode in Admin Settings, classifies agent runs that finish with warnings, and adds a Show Status modal to inspect how a run ended.

---

## Highlights

- **Auto Agent Exclusions**: Admins can now uncheck individual agents (Antigravity, Claude Code, Codex CLI, OpenCode) to keep them out of Auto Mode selection. Directly selected agents are unaffected.
- **Show Status Modal**: Agent and script result cards have a Show Status action that reveals the run's outcome and raw exit code.
- **Completed With Warnings Outcome**: Agent runs that complete but emit warning signals are classified as `completed_with_warnings` instead of being treated as plain successes or failures.

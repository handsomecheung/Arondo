# Arondo v0.3.1

**Release Date:** 2026-10-17
**Commits:** 5
**Tag:** v0.3.1

This patch release improves one-time sessions and agent reruns, adds directory creation to the file picker, and includes a lint compatibility fix.

---

## Highlights

- **Create Directories from the File Picker**: Create a folder while browsing the runner filesystem, without leaving the project selection flow.
- **More Reliable One-Time Sessions**: One-time session cache data is deleted with the session, and Auto Model routing is restricted to those sessions as intended.
- **Stable Agent Reruns**: Rerunning an agent preserves the selected agent type.

---

## Changes

### Features

- Restrict Auto Model routing to one-time sessions and simplify completed agent cards (`744dd75`)

- Remove one-time session cache data when its session is deleted (`96ccb0b`)

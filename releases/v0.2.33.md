# Arondo v0.2.33

**Release Date:** 2026-09-01
**Commits:** 9
**Tag:** v0.2.33

This release adds configurable per-agent model catalogs, improves Auto Mode
routing and session recovery, refreshes the Claude and Codex model lineups,
and fixes handling of encoded file paths in agent output.

---

## Highlights

- **Configurable Agent Models**: Administrators can customize model lists for
  supported agents, including `#` comments and guidance displayed in Settings.
  Invalid Antigravity model selections are detected before execution.
- **Improved Auto Mode**: Auto Mode supports the restored GPT-OSS 120B option,
  uses the current Gemini Flash 3.7 default, and preserves recent-session
  navigation briefly to avoid interrupting active work.
- **Current Model Catalogs**: Updated Codex to the GPT-5.6 and GPT-5.x lineup
  and added Claude model descriptions and pricing notes for clearer selection.
- **Robust File Links**: Markdown file-link detection now safely handles malformed
  URI encodings instead of failing while rendering agent output.

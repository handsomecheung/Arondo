# Arondo v0.3.16

**Release Date:** 2026-11-11
**Commits:** 5
**Tag:** v0.3.16

This patch release adds Pi as a supported agent across the CLI, runner, Auto Mode, and UI, keeps tasks open across runner disconnects, and improves agent failure classification and Automodel reliability.

---

## Highlights

- **Pi Agent Integration**: Pi is now supported across the CLI, runner, Auto Mode, and UI, including agent models, quota display, and the Runners dashboard.
- **Runner Disconnect Handling**: Tasks stay open when a runner disconnects, and runner loss is recorded separately from task outcomes instead of marking the task as failed.
- **Failure Classification**: Only stdout is sent to Jev for agent failure classification when stdout is present, giving more accurate outcomes.
- **Automodel Timeout**: The Automodel Jev timeout has been increased to three seconds to reduce spurious fallbacks.

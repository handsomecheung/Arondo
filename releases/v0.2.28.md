# Arondo v0.2.28

**Release Date:** 2026-08-27
**Commits:** 4
**Tag:** v0.2.28

This release introduces PWA push notifications for task completion, polishes the
Settings UI with a card layout, renames CLI connection settings for clarity, and
adds minor maintenance improvements.

---

## Highlights

- **PWA push notifications**: The app now requests notification permission and
  delivers a browser push notification when a background task completes, keeping
  you informed even when the tab is in the background.
- **Settings card layout**: Each settings section is now styled as a visually
  distinct card, making the Settings page easier to scan and navigate.
- **CLI connection setting rename**: The CLI's `server` / `clientToken` config
  keys are renamed for clarity, keeping the developer experience consistent with
  the rest of the codebase.

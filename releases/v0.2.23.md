# Arondo v0.2.23

**Release Date:** 2026-08-23
**Commits:** 7
**Tag:** v0.2.23

This release replaces the old script-based automation CLI with a Go CLI,
adds runner/agent inspection commands, expands quota refresh support, and
updates release builds to ship both runner and CLI binaries.

---

## Highlights

- **Go CLI**: `cli/arondo-cli` replaces the previous `bin/arondo` script with a dependency-free Go implementation for session creation, resume, polling, and result output.
- **CLI Configuration**: CLI commands can read `cli.url` and `cli.token` from `~/.arondo/arondo.json`, with flags and environment variables still taking precedence.
- **Runner Readiness Commands**: Added `list-agents`, `get-quota`, and `update-quota` commands for checking accessible runner agents and quota state from automation.
- **Release Binaries**: Tagged releases now build both runner and CLI binaries for Linux amd64, macOS amd64, and macOS arm64.

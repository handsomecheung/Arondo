# Arondo v0.3.10

**Release Date:** 2026-11-04
**Commits:** 4
**Tag:** v0.3.10

This patch release adds OpenCode quota reporting for free, API-key, and unauthenticated installations, consistently resolves agent runs to the configured default model, retires the legacy `--temp-dir` option in favor of automation session retention cleanup, and updates the OpenCode and Codex agent icons.

---

## Highlights

- **Consistent Default Model Resolution**: Direct agent selections and Auto Mode runs (including locked follow-ups, retries, and detached runs) now always resolve to the configured `defaultModel` when no explicit model is specified, omitting `--model` on the command line only when `defaultModel` is empty.
- **OpenCode Billing State Reporting**: Runners now report an OpenCode quota record for free Console accounts, API-key billed accounts, unauthenticated installations, and unreadable responses so the server does not repeatedly poll installations without Go subscriptions and the UI clearly labels their billing state. Only the `Go` plan remains eligible for Auto Mode's OpenCode fallback.
- **Retired `--temp-dir` & Automation Session Cleanup**: Removed the deprecated `--temp-dir` CLI flag and `tempDir` session/project fields, added a migration script for existing records, and moved retention cleanup to `automationSessionRetentionHours` while preserving runner workspaces.
- **Updated Agent Icons**: Refreshed the SVG icons for OpenCode and Codex in `components/Icons.tsx`.

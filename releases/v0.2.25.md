# Arondo v0.2.25

**Release Date:** 2026-08-25
**Commits:** 8
**Tag:** v0.2.25

This release adds automodel routing for Auto Mode model and effort selection,
renames the auto routing surface to Auto Mode terminology, improves temporary
directory project handling, and sharpens CLI status output.

---

## Highlights

- **Automodel routing**: Auto Mode can now make a second-stage model and effort
  choice from the agent's available options using configured Anthropic, OpenAI,
  or Google API keys.
- **Automodel settings and diagnostics**: Settings can store LLM API keys for
  automodel routing, and routing decisions now write debug logs for inspection.
- **Temporary directory projects**: Sessions created with `tempDir` are marked
  explicitly so task and archive APIs can hide or handle them consistently.
- **CLI improvements**: The CLI skips runner resolution when creating temp-dir
  sessions and shows the currently running agent in message history output.
- **Bundled CLI skill rename**: The installed skill has been renamed from
  `arondo-agent` to `arondo-cli`.

# Arondo v0.2.49

**Release Date:** 2026-10-07
**Commits:** 3
**Tag:** v0.2.49

This release strengthens client isolation for project listings, makes long project paths easier to identify in the project picker, and treats intentionally stopped agent sessions as completed rather than failed.

---

## Highlights

- **Client-Scoped Project Listings**: Projects are now shown only when they are associated with the authenticated client token through an active or archived session, preventing cross-client project visibility.
- **Readable Long Project Paths**: The project selector now shows the folder name alongside a responsive middle-truncated path, preserving useful path context on narrow screens.
- **Clean Stopped Session State**: User-stopped agent runs now finish with a completed session state and no error message, while retaining the explicit “Stopped by user” timeline notice.
